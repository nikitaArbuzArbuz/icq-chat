# ICQ Chat

Чат один на один в стиле ICQ. Пользователи регистрируются, переписываются в реальном времени и видят статусы сообщений — отправлено, доставлено, прочитано. Все сообщения хранятся в PostgreSQL.

## Возможности

- Регистрация и вход по логину и паролю, авторизация через JWT.
- Список контактов: поиск по началу логина, онлайн-индикатор, счётчик непрочитанных, сортировка по последнему сообщению.
- «Избранное» — переписка с самим собой, всегда первая в списке.
- История переписки: старые сообщения подгружаются при прокрутке вверх.
- Отправка через WebSocket без дублей при повторной отправке.
- Статусы SENT → DELIVERED → READ обновляются у отправителя в реальном времени.
- Сообщения, пришедшие офлайн, досылаются при подключении.
- Несколько вкладок одного пользователя синхронизируются.
- Heartbeat и автоматическое переподключение клиента.
- Защита от подбора пароля, быстрый отказ при перегрузке базы.
- Светлая и тёмная темы, вёрстка под узкие экраны.

## Стек

| Часть | Технологии |

## Быстрый старт через Docker

Нужны Docker и Docker Compose.

```bash
docker compose up --build
```

- веб-интерфейс: http://localhost:3000
- API бэкенда напрямую: http://localhost:8080
- PostgreSQL: localhost:5432

Переменные берутся из `.env` в корне. Остановить и удалить данные: `docker compose down -v`.

## Тестовые пользователи

Создаются миграцией при первом запуске, только для демонстрации:

| Логин | Пароль |
|---|---|
| `alice` | `password123` |
| `bob` | `password123` |

## Как быстро проверить чат

1. Запусти проект: `docker compose up --build`.
2. Открой http://localhost:3000 и войди как `alice` / `password123`.
3. В окне инкогнито или другом браузере войди как `bob` / `password123`.
4. У Алисы Боб отмечен зелёной точкой — он в сети.
5. Напиши сообщение. У отправителя появится значок ожидания, затем одна серая галочка (сохранено), две серые (доставлено) и две синие, когда получатель откроет переписку.
6. Закрой окно Боба и напиши ему. Останется одна галочка. Войди за Боба снова, сообщение дошлётся, и у Алисы галочки обновятся.
7. Открой вторую вкладку за Алису. Сообщения и прочтения синхронизируются между вкладками.

## Локальный запуск без Docker

Нужны JDK 21, Node.js 20+ и PostgreSQL 16 (можно поднять только базу: `docker compose up -d postgres`). Gradle ставить не нужно: в `backend` лежит Gradle Wrapper. На Windows вместо `./gradlew` запускай `gradlew.bat`.

```bash
# бэкенд на :8080, миграции применяются при старте
cd backend
./gradlew run

# фронтенд на http://localhost:5173, в другом терминале
cd frontend
npm install
npm run dev
```

Dev-сервер Vite проксирует `/api` и `/ws` на `localhost:8080`. Сборка: `./gradlew installDist` для бэкенда, `npm run build` для фронтенда.

### Переменные окружения

Бэкенд читает `.env` из текущей папки или корня репозитория, если чего-то нет, то об этом он скажет.

```env
PORT=8080
DB_HOST=localhost
DB_PORT=5432
POSTGRES_DB=chat
POSTGRES_USER=chat
POSTGRES_PASSWORD=chat
DB_POOL_SIZE=10
JWT_SECRET=<не короче 32 символов>
JWT_TTL_HOURS=24
```

## Тесты

```bash
cd backend
./gradlew test
```

Нужен только работающий Docker. Интеграционные тесты поднимают приложение и PostgreSQL через Testcontainers и общаются с сервером как клиент, по HTTP и WebSocket. Покрыты авторизация и лимиты входа, идемпотентная отправка, статусы, досылка офлайн-сообщений, онлайн-статусы, пагинация истории, контакты и поиск, валидация текста, таймауты пула.

## API

Все эндпоинты, кроме регистрации, входа и `/health`, требуют заголовок `Authorization: Bearer <token>`.

WebSocket: `ws://localhost:8080/ws?token=<JWT>`, все сообщения — JSON с полем `type`. Невалидный или истёкший токен закрывает соединение с кодом `4401`, молчание клиента дольше 45 секунд — с кодом `4408`.


| Запрос | Что делает |
|---|---|
| `POST /api/auth/register` | регистрация |
| `POST /api/auth/login` | вход, возвращает токен |
| `GET /api/me` | текущий пользователь |
| `GET /api/users?search=` | список контактов и поиск |
| `GET /api/messages/{userId}?before=&limit=` | история переписки |
| `GET /health` | проверка, что сервер жив |

## Некоторые ограничения

- Сессии, онлайн-статусы и счётчики попыток входа хранятся в памяти, поэтому сервер рассчитан на один экземпляр. 
- JWT нельзя отозвать до истечения срока, refresh-токенов нет.
- Токен WebSocket передаётся в строке запроса.
- В списке контактов не больше 100 записей, остальных можно найти поиском.
